## Question

Replace the native `<select>` for "Auto-lock after hiding the app" (`IdentitiesScreen.tsx`) with `@kobalte/core/select`. This is the smallest, lowest-risk form control and pins the alpha's collection-based Select API for the rest of the adoption.

## What to pin (alpha API is collection-based, differs from Kobalte 0.13)

- **`Select.Root` options shape**: `options={[...CollectionNode]}` — confirm the exact node shape (`{ value, label }` vs richer), how `defaultValue`/`onChange` map to the signal-backed `prefs().autoLockMinutes`.
- **Selection render**: how `Select.Value` exposes the selected node (render-prop? `state.selectedOption()`?) to show "5 minutes".
- **Styling hooks**: the `data-*` attributes Kobalte sets (open/selected/disabled) and how to map them to the existing Tailwind B/W classes via `@kobalte/tailwind` or plain `data-*` selectors — the repo has no `@kobalte/tailwind` yet; decide add-vs-handroll.
- **Touch/keyboard on small screen**: confirm the alpha popover behaves on tap + arrow keys, which is the whole reason to adopt it.

## Acceptance

- Auto-lock selector renders via Kobalte Select, matches the B/W theme, updates `prefs` (optimistic path unchanged), passes the current optimistic-persistence check (select 5 min → reload → 5 min selected).
- The alpha Select API is pinned in this ticket (option shape, value render, styling hooks) so K2/K3/K4 follow without re-derivation.
- `tsc -b` + `npm test` green; no console warnings.
