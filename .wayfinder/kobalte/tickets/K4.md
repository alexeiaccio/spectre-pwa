## Question

Replace the native `<input type="number">` "Spectre counter" (SiteFields add/edit) with `@kobalte/core/number-field`.

## Notes

- Counter is `min 1`, integer, currently clamped via `Math.max(1, Number(...))` in the `onInput` handler. NumberField gives stepper + keyboard + the same clamp semantics; confirm how `onChange`/`value` map to `SiteFormState.counter`.
- On a tiny screen, the stepper buttons must stay within the `w-16` compact row.

## Acceptance

- Counter edits (add + edit) work through NumberField, still clamped ≥1, persisted via the existing optimistic `commitMutation`.
- Row layout unchanged on small screens.
